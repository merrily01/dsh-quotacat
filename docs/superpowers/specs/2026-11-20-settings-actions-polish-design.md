# QuotaCat 设置交互收尾设计

## 意图

让额度详情中的设置入口更容易识别，让自动刷新保持单行，并用明确的“取消 / 保存更改”替代含糊的“返回”。

## 设计

- 额度详情底部右侧按“刷新、设置”排序；设置使用 16px SVG 齿轮和约 26px 的点击热区。
- 自动刷新继续使用单个下拉框，左侧标签、右侧当前值固定在同一行；选择框宽度约 100px。
- 设置页底部只保留“取消”和“保存更改”。取消不保存并返回额度详情；保存成功后返回额度详情；保存失败则留在设置页。
- 未修改时允许保存当前值，不额外引入脏状态和复杂确认框。

## 取舍

- 采用设置页内成对操作按钮，而不是保留独立“返回”，因为“取消”能明确表达未保存修改的处理方式。
- 不把设置入口放进标题栏，避免与当前额度值争夺位置。
- 不恢复多个刷新频率胶囊选项，保持弹层紧凑。

## 非目标

- 不新增额度预测、多供应商聚合或其他业务能力。
- 不修改额度数据获取和通知规则。
