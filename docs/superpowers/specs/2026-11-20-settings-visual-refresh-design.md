# QuotaCat 设置页视觉整理设计

## 目的

将新增的 DSH QuotaCat 设置入口整理为紧凑、克制的设置表单，延续原版 macOS QuotaCat 的分组层级，同时服从 DSH 的主题和弹窗尺寸。

## 范围

- 保留自动刷新、额度阈值提醒和阈值百分比三个可配置项。
- 自动刷新使用单行下拉框，不再展示六个胶囊按钮。
- 通知开关、阈值数值和滑块放在同一分组。
- 删除 API Key、凭据来源、连接状态和支持作者入口。
- 保存按钮缩小并右对齐；保存成功后停留在设置页并短暂显示“已保存”。
- 不修改额度详情、composer pill、凭据获取逻辑和服务端设置接口。

## 视觉方案

采用“QuotaCat 分组结构 + DSH 设计变量”：分组标题位于控件容器之外，容器使用轻量边框而非大面积灰底；刷新频率是一行 label/select；通知分组用分隔线组织开关与阈值；唯一强调色用于开关、滑块和保存按钮。

## 备选方案

- 完全复用 DSH 默认设置列表：最稳，但缺少 QuotaCat 辨识度。
- 保留卡片与胶囊选择：操作直观，但在 300–440px 弹窗内过重，已被否决。

## 约束

- 继续使用现有内联 CSS 和 `React.createElement` 写法。
- 支持暗色/亮色主题、键盘焦点及窄视口。
- 不新增运行时依赖。
